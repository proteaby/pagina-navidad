
# Christmas Diaries 🎄 – Proyecto Final de Course Frontend

Este es mi proyecto final para mis cursos de Frontend.
Elegí crear la página web Christmas Diaries porque amo profundamente la Navidad en general y por la época. 
Quería hacer una página que reflejara todo eso y que reuniera mis cosas favoritas de la temporada.
Esta página web también es mi pequeño universo navideño hecho con cariño.

Pueden acceder a ella en el siguiente link, ojalá les guste: https://proteaby.github.io/pagina-navidad/ 

## 🎅 Redes sociales del proyecto
Para hacerlo aún más especial, también creé redes sociales dedicadas a la página, dónde publico contenido inspirado en la magia navideña.

El objetivo de esta página web fue plasmar mis habilidades aprendidas en el curso, pero también compartir un proyecto que realmente amo y que representa algo muy personal para mí: mi cariño por la Navidad.
## ✨Tecnologías empeladas: HTML, Git y Github

Esta página la realicé como proyecto final en DEVF gracias a Becalos Tech Challenge por el aprendizaje y por mi sensei que siempre fue paciente y nos apoyó muchísimo.
